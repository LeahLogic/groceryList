# Grocery List 🛒

A simple and interactive grocery shopping list application built with React and Vite. The app helps users organize their shopping items and keep track of what they need to buy.

## Features

- **Add Items** — Enter grocery items and add them to the shopping list.
- **Mark as Purchased** — Click on an item to cross it off the list.
- **Unmark Items** — Click again to remove the crossed-out style.
- **Clear List** — Remove all items using the Delete button.
- **Input Validation** — Display an alert when trying to add an empty item.
- **Simple Interface** — Clean layout with shopping illustrations and easy-to-use controls.

## Getting Started

To run this project locally:

1. Clone or download the repository.
2. Open the project folder in your code editor.
3. Install dependencies:

   `npm install`

4. Start the development server:

   `npm run dev`

5. Open the local URL displayed in your terminal.

## How to Use

1. Type a grocery item into the input field.
2. Click **Add** to add it to your list.
3. Click an item to mark it as purchased.
4. Click the item again to remove the crossed-out style.
5. Click **Delete** to clear the entire shopping list.

**Note:** Items are stored in React state and will reset when the page is refreshed.

## About the Project

Grocery List is a learning project created to practice React fundamentals, including class components, state management, user interactions, and dynamic list rendering.

The project focuses on building a functional and interactive user interface using React and JavaScript.
